# Beltometer

Измеритель пропускной способности конвейерной ленты для Factorio 2.0.

## Использование

1. Изучите технологию **Beltometer** (требует `circuit-network`).
2. Скругните устройство и подключите его красным или зелёным проводом к конвейерной ленте.
3. На ленте включите **«Читать содержимое → Импульс»** (pulse mode).
4. Пустите предметы по ленте — через секунду над устройством появится текст с пропускной способностью.

## Возможности

- **Два режима отображения:** суммарная пропускная способность по всем предметам или по каждому отдельно.
- **Единицы измерения:** `/сек`, `/мин`, `/час`.
- **Окно усреднения:** настраивается от 1 до 600 тиков (0.017–10 с).
- **Алгоритмы:** SMA (простое скользящее среднее) и EMA (экспоненциальное скользящее среднее).
- **Настройки через GUI:** клик по устройству открывает окно конфигурации.

## Рецепт

- 5× iron-plate
- 5× copper-cable
- 5× electronic-circuit

## Совместимость

- Factorio 2.0
- Базовая игра (требуется только `base`)
- Мультиплеер
- Любые моды на ленты (сигналы читаются через circuit network)
